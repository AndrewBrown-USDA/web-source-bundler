# 1.2.3 — T2.3-markdown-and-redact

## Goal
Implement HTML to Markdown conversion, regex redaction, YAML-front-matter source markdown generation, and combined multi-source markdown bundle document construction in `source_bundler/markdown.py`, verified with unit tests in `tests/test_markdown.py`.

## TODO items
- [x] Create `source_bundler/markdown.py` with:
  - [x] `html_to_markdown(html_content: str, strip_tags: Optional[List[str]] = None) -> str`:
    - Converts HTML content to clean Markdown using `markdownify` (or BeautifulSoup pre-processing with `markdownify`).
    - Supports `strip_tags` to remove unwanted elements (e.g. script, style, nav, footer).
    - Preserves headings, lists, tables, code blocks, and links with clean whitespace normalization.
  - [x] `apply_redactions(text: str, patterns: Optional[List[str]]) -> str`:
    - If `patterns` is provided and non-empty, compiles regex patterns and substitutes matches with `[REDACTED]`.
    - Returns original text if `patterns` is None or empty.
  - [x] `build_readable_markdown(source_id: str, title: str, input_url: str, final_url: str, fetched_at: str, http_status: Optional[int], content_md: str, extracted_links: Optional[List[Tuple[str, str]]] = None, include_links_table: bool = False, redact_patterns: Optional[List[str]] = None) -> str`:
    - Generates YAML front matter enclosed between `---` containing `source_id`, `title`, `input_url`, `final_url`, `fetched_at`, and `http_status`.
    - Applies `apply_redactions` with `redact_patterns` to `content_md`.
    - If `include_links_table` is True and `extracted_links` is provided, appends a Markdown table `| Text | URL |` (also redacted if patterns match).
    - Returns combined string with proper line breaks.
  - [x] `build_combined_markdown(manifest: Manifest, source_markdowns: Dict[str, str]) -> str`:
    - Generates bundle header: `# Source Bundle`, `Bundle ID: <bundle_id>`, `Created: <created_at>`, `Tool: <tool.name> v<tool.version>`.
    - Includes usage prompt instructions (`Use this document as the reference source bundle. Cite material by source ID.`).
    - Generates Index table/section listing each source with ID, Title, Status, and SHA-256 hash.
    - Generates per-source sections: `## Source <source_id>: <title>`, `Input URL`, `Final URL`, `Fetched`, `SHA-256 readable Markdown`, `### Content`, followed by readable markdown body or failure/error notice.
- [x] Create unit tests in `tests/test_markdown.py`:
  - [x] `test_html_to_markdown`: basic HTML with headings, lists, links, code blocks, tables, and `strip_tags`.
  - [x] `test_apply_redactions`: multiple regex patterns (e.g. API keys, emails), empty patterns list, None patterns, overlapping/repeated matches.
  - [x] `test_build_readable_markdown`: YAML front matter validation, content redactions, extracted links table formatting when `include_links_table=True` and `False`.
  - [x] `test_build_combined_markdown`: header, usage prompt, index table, per-source sections for successful captures and error/missing captures.
- [x] Run acceptance command: `python -m pytest tests/test_markdown.py -v`.
