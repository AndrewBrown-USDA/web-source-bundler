# 1.3.1 — T3.1-playwright-capture

## Goal
Implement deterministic browser capture using Playwright in `source_bundler/capture.py` (with configurable defaults, isolated context, service workers disabled, DOM content loaded + network idle wait, screenshot, PDF, rendered HTML, and non-fatal error trapping into `CaptureResult`) and verify with comprehensive unit tests in `tests/test_capture.py`.

    - Isolated browser context per capture

    - Launch headless async Playwright chromium browser.
    - Create new isolated context with deterministic config & route handlers to block service workers.
    - Intercept main navigation response to record initial/raw HTML if `save_raw_html` is True, HTTP status, and response headers.
    - Navigate to URL with wait condition `domcontentloaded`, followed by short network idle wait (`wait_for_load_state("networkidle", timeout=...)`) wrapped in timeout rescue.
    - Retrieve final URL, page title, and rendered HTML (`page.content()`).
    - Capture full-page screenshot (`page.screenshot(full_page=True)`) if `save_screenshot` is True.
    - Capture PDF (`page.pdf(print_background=True)`) if `save_pdf` is True.
    - Trap all Playwright / navigation / timeout / network exceptions gracefully and append `SourceError(stage="capture", message=str(exc), timestamp=datetime.now(timezone.utc))` to `result.errors`.
  - [x] `def run_capture(url: str, config: Optional[CaptureConfig] = None, save_screenshot: bool = True, save_pdf: bool = True, save_raw_html: bool = False) -> CaptureResult`:
    - Synchronous wrapper around `asyncio.run(capture_url(...))` with safe event loop handling (e.g. handling already-running or fresh event loops).

## Notes
- Discovered models: `CaptureConfig`, `ViewportConfig`, and `SourceError` exist in `source_bundler/models.py`.
- Constraints honored: Files touched strictly limited to `source_bundler/capture.py` and `tests/test_capture.py`. `bundle.py` is NOT touched.
- Non-fatal error handling: All network errors, Playwright timeouts, DNS errors, or rendering failures will populate `CaptureResult.errors` and will not raise unhandled exceptions.
- Test design: Unit tests will mock Playwright components to ensure 100% offline, deterministic, and fast test execution without external network calls.
