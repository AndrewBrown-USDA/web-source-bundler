# 1.3.2 — T3.2-bundle-packager

## Goal
Implement the core bundle packaging engine in `source_bundler/bundle.py` that processes captured sources, writes all source artifacts, structured AST documents, sanitized/redacted Markdown, metadata, top-level manifest, combined reference Markdown, and cryptographic SHA-256 checksums, verified by unit tests in `tests/test_bundle.py`.

## TODO items
- [x] Create `source_bundler/bundle.py` implementing `BundlePackager`:
  - [x] `__init__(self, out_dir: Optional[Union[str, Path]] = None, config: Optional[CaptureConfig] = None, redact_patterns: Optional[List[str]] = None, include_links_table: bool = False, include_raw_html: bool = False)`:
    - Initialize bundle ID via `generate_bundle_id()`.
    - Set target `out_dir` (custom or `./source-bundle-YYYYMMDDTHHMMSSZ`).
    - Create bundle directory and `sources/` subdirectory.
    - Initialize internal tracking lists/dicts for `SourceRecord`s and generated readable markdown texts.
  - [x] `add_source(self, source_id: str, input_url: str, capture_result: Any, selected: bool = True, selection_note: Optional[str] = None) -> SourceRecord`:
    - Create source directory `sources/{source_id}/`.
    - Handle successful capture:
      - Write `rendered.html` when `rendered_html` is present.
      - Write `raw.html` and `response_headers.json` if `include_raw_html` is enabled and present.
      - Extract clean content via `extract_readable_html` and structured AST via `build_ast_document`, then write `ast.json`.
      - Convert to markdown with `html_to_markdown` and build front-matter readable markdown with `build_readable_markdown` (applying redaction patterns and optional extracted links table), then write `readable.md`.
      - Write binary `screenshot.png` and `page.pdf` if bytes are present in `capture_result`.
    - Handle failed capture / errors:
      - Capture errors in `SourceRecord.errors` as `SourceError` objects.
    - Compute SHA-256 for all generated source artifact files using `hashing.hash_file`.
    - Build `ArtifactRefs` with relative POSIX paths (e.g. `sources/{source_id}/rendered.html`).
    - Write `sources/{source_id}/metadata.json` with formatted JSON representation of `SourceRecord`.
    - Save readable markdown content into internal source markdown map for `combined.md`.
    - Append record to `self.sources` and return `SourceRecord`.
  - [x] `finalize(self) -> Path`:
    - Instantiate and write `manifest.json` formatted JSON using `Manifest` model.
    - Generate combined markdown document using `build_combined_markdown` and write `combined.md`.
    - Collect relative paths and calculate SHA-256 hashes for all bundle files (`manifest.json`, `combined.md`, and all files in `sources/**` except `checksums.sha256`).
    - Generate and write `checksums.sha256` using `generate_checksums_content`.
    - Return `Path` to bundle root directory.
- [x] Create unit tests in `tests/test_bundle.py`:
  - [x] Test `BundlePackager` initialization with default directory generation and custom `out_dir`.
  - [x] Test `add_source` with successful capture result:
    - Verify creation of `rendered.html`, `ast.json`, `readable.md`, `screenshot.png`, `page.pdf`, `metadata.json`.
    - Verify `ArtifactRefs`, `hashes`, and metadata content.
  - [x] Test `add_source` with optional raw HTML and headers flags.
  - [x] Test `add_source` with redaction patterns and link extraction table options.
  - [x] Test `add_source` with failed capture result (errors populated, partial artifacts, metadata.json written).
  - [x] Test `finalize`:
    - Verify creation and structure of `manifest.json`.
    - Verify creation and contents of `combined.md`.
    - Verify generation of `checksums.sha256` matching all created files with correct POSIX paths.
    - Verify return path matches bundle root.
  - [x] Run acceptance command: `python -m pytest tests/test_bundle.py -v`.

## Notes
- Constraints honored: `source_bundler/capture.py` is NOT touched. Only `source_bundler/bundle.py` and `tests/test_bundle.py` are created/edited.
- Reusable modules: `models.py` (`Manifest`, `SourceRecord`, `ArtifactRefs`, `SourceError`, `CaptureConfig`), `hashing.py` (`hash_file`, `generate_checksums_content`), `utils.py` (`generate_bundle_id`, `format_utc_timestamp`), `extract.py` (`extract_readable_html`, `build_ast_document`), and `markdown.py` (`html_to_markdown`, `build_readable_markdown`, `build_combined_markdown`).
- File paths in `manifest.json`, `metadata.json`, and `checksums.sha256` will be normalized to POSIX relative paths.
