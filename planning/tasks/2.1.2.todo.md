## Objectives
1. Update `build_combined_markdown` header metadata format to match spec exact format:
   ```markdown
   # Source Bundle

   Bundle ID: {bundle_id}  
   Created: {created_at}  
   Tool: {tool_name} {tool_version}

   Use this document as the reference source bundle. Cite material by source ID.
   ```
2. Make `include_index` an optional parameter in `build_combined_markdown` (default `False` to strictly match spec unless requested) or format source section lines to match spec (`- Input URL: ...`, etc.).
3. Bundle loose parameters in `build_readable_markdown` by introducing a `ReadableSourceContext` dataclass / helper model or accepting kwargs / dataclass while preserving complete backward compatibility with positional/keyword arguments.
4. Verify using `python -m pytest tests/test_markdown.py`.
5. Update `planning/STATE_2.md` under `## 2.1.2`.
