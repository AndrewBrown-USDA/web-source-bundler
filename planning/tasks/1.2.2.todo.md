# 1.2.2 — T2.2-extract-and-ast

## Goal
Implement readable HTML extraction, tag sanitization, and structured block-level AST document generation in `source_bundler/extract.py`, verified with comprehensive unit tests in `tests/test_extract.py`.

## TODO items
- [ ] Implement `extract_readable_html(raw_html: str, url: Optional[str] = None) -> Tuple[str, str]` in `source_bundler/extract.py`:
  - [ ] Use `readability.Document` (or BeautifulSoup fallback if readability fails/is absent) to extract page title and main article/body HTML.
  - [ ] Sanitize extracted HTML by removing unwanted elements: `script`, `style`, `noscript`, `svg`, `canvas`, `nav`, `footer`, and common cookie banner selectors / classes / IDs (`#cookie-banner`, `.cookie-notice`, `[role="alertdialog"]`, etc.).
  - [ ] Retain semantic tags (`h1`-`h6`, `p`, `ul`, `ol`, `li`, `blockquote`, `pre`, `code`, `table`, `thead`, `tbody`, `tr`, `th`, `td`, `a`) while stripping unsafe/useless attributes.
  - [ ] Return clean `(title, cleaned_html)`.
- [ ] Implement `build_ast_document(source_id: str, title: str, final_url: str, cleaned_html: str) -> ASTDocument` in `source_bundler/extract.py`:
  - [ ] Parse `cleaned_html` using BeautifulSoup into structured sequence of `ASTBlock` objects.
  - [ ] Support block types:
    - `heading`: `level` (1-6), `text`.
    - `paragraph`: `text`.
    - `list`: `items` (list of item texts), `extra={"ordered": bool}`.
    - `blockquote`: `text`.
    - `code_block`: `text`, `extra={"language": Optional[str]}` (extracted from class e.g. `language-python` if present).
    - `table`: `rows` (list of row cell text lists), `extra={"headers": Optional[List[str]]}` if `th` elements present.
    - `link`: standalone or key extracted link elements with `text` and `href`.
  - [ ] Return `ASTDocument(source_id=source_id, title=title, final_url=final_url, blocks=blocks)`.
- [ ] Create unit tests in `tests/test_extract.py`:
  - [ ] `test_extract_readable_html_basic`: Extract title and clean content from a standard HTML snippet with noise tags (`script`, `nav`, `footer`, `style`).
  - [ ] `test_extract_readable_html_fallback`: Verify fallback behavior on minimal/broken HTML.
  - [ ] `test_extract_readable_html_cookie_removal`: Ensure cookie banner/notice elements are removed.
  - [ ] `test_build_ast_document_headings_and_paragraphs`: Validate headings with levels (h1-h6) and paragraphs.
  - [ ] `test_build_ast_document_lists`: Validate ordered and unordered lists and items.
  - [ ] `test_build_ast_document_code_blocks`: Validate `pre`/`code` blocks with language detection.
  - [ ] `test_build_ast_document_tables`: Validate tables with header and body rows.
  - [ ] `test_build_ast_document_blockquotes_and_links`: Validate blockquotes and standalone links.
  - [ ] `test_build_ast_document_empty_or_whitespace`: Validate handling of empty HTML.
- [ ] Run acceptance test: `python -m pytest tests/test_extract.py -v`.
