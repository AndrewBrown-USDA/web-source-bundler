# 1.1.2 — T1.2-utils-and-hashing

## Goal
Implement filename sanitization, timestamp formatting, bundle ID generation, and URL normalization in `source_bundler/utils.py`, along with SHA-256 hashing functions and checksums file generation in `source_bundler/hashing.py`, verified with complete unit tests.

## Notes
- Scope strictly restricted to `source_bundler/utils.py`, `source_bundler/hashing.py`, `tests/test_utils.py`, and `tests/test_hashing.py`.
- No modifications to `models.py` or `pyproject.toml`.
- All hashes must follow the `sha256:<hex>` scheme in helper return values, but `generate_checksums_content` must strip `sha256:` prefix for standard `sha256sum` compatibility.
- Ensure cross-platform path normalization using POSIX relative paths (`/`) for `checksums.sha256` output.
- All timestamps default to UTC using standard library `datetime.now(timezone.utc)`.
